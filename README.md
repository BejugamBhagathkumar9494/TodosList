# Todo List Application

A simple Todo List application to manage daily tasks efficiently. It allows users to create, update, and delete tasks while keeping track of their completion status.

---

## Features

* Add new tasks
* Update/edit tasks
* Mark tasks as completed
* Delete tasks
* View list of all tasks

---

## Tech Stack

* HTML
* CSS
* JavaScript

---

```
todo-list/

```

## Installation

1. Clone the repository:

```
git clone https://github.com/your-username/todo-list.git
```

2. Navigate to the project directory:

```
cd todo-list
```

3. Open `index.html` in your browser

---

## Usage

* Enter a task and add it to the list
* Update tasks when needed
* Mark tasks as completed
* Delete tasks when finished
